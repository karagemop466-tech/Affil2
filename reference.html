How this page is meant to be used

Readers never have to see this page — the front page leads with products and buyer questions. Reviewers and future sessions work here: verify a value, resolve a flagged conflict, choose a suggestion path, then let the publishing gate (disclosure, sponsored marking, source links) check the result before anything goes live. Machine-checkable gates run in scripts/check_site.py on every push.
