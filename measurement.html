Measurement, Collector & Search Console Setup

Static GitHub Pages hosting cannot run backend code, so visitor metrics stay in your browser by default. When you are ready for cross-visitor counts without cookies or third-party scripts, this repository already includes the zero-dependency collector and strict schema below.

1. Five-event schema (data/events.json)

Privacy contract v1.0. Disallowed fields (ip, user_agent, referrer, cookie, fingerprint, query_text, email, session_id) are stripped client-side and rejected with HTTP 400 by the collector.
EventTrigger Allowed fieldsPurpose
page_viewAny generated page finishes loadinge, t, pageUnderstanding which pages are visited
outbound_clickA tagged Amazon affiliate link ([data-outbound]) is clickede, t, page, productMeasuring which product a reader clicks out to
guide_readA buying guide under guides/ finishes loadinge, t, pageSeparating guide consumption from catalog navigation
searchOn-site search evaluates a non-empty query on search.htmle, t, page, q_len, resultsDetecting zero-result searches via query length and match count without recording raw user text
suggestion_rankA proposal row on suggestions.html is moved up or downe, t, page, rankRecording reviewer priority ordering in Decision Center

2. How browser logging and send() behave

  • Default on GitHub Pages: All five events are appended to localStorage (sn_events, capped at 500 records) and outbound clicks increment sn_clicks. No network request fires while no collector endpoint is set (FLG-010).
  • Activating the self-hosted collector: Set <meta name="sn-collect-endpoint" content="/api/collect">, define window.SN_COLLECT_ENDPOINT, or set localStorage.setItem('sn_collect_url', ...). send() strips disallowed keys, rounds timestamps to the nearest minute, and sends a cookieless POST (credentials: 'omit').
  • Search privacy: The search event records only query length (q_len) and match count (results), never the words typed by a reader.

3. Running the self-hosted collector

Option A — Node.js zero-dependency server (analytics/server.js):

HOST=0.0.0.0 PORT=8787 COLLECT_LOG_FILE=/var/log/shopnow/events.ndjson node analytics/server.js

  1. RSS capture (live now): feed.xml is valid RSS 2.0 listing all 11 buying guides and linked from every page head and footer.
  2. Google Search Console (owner action): Verify property ownership for https://karagemop466-tech.github.io/Affil2/ (or custom domain under SG-14), submit https://karagemop466-tech.github.io/Affil2/sitemap.xml, and track impressions/CTR to choose new guide topics (SG-29, SG-32).
