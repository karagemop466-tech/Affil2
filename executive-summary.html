What is not verified

  • Owner intent. Intended ASIN and its confirmation date/source are blank for all five products (FLG-001).
  • Associates account and tracking. The tracking ID’s issuance/activity and the one-per-product Special Link test require the enrolled account (FLG-002, FLG-004).
  • Short-link compliance. It remains unresolved; the site does not call the submitted links valid or invalid (FLG-003). Four previous recorded attempts resolved to a product page; P-04 returned a checkpoint, not a product destination (FLG-011, FLG-012).
  • Independent testing and certificates. No product was tested; seller-stated certifications have not been independently verified (FLG-032, FLG-035).
  • Full live-page transcript. Amazon listings are dynamic. This pass reviewed available excerpts, not a complete line-by-line capture of each live page; unsupported values remain blank and the source rows identify the page and review scope (FLG-023).

Hosting and discovery are open decisions

GitHub’s Pages limits documentation raises a question about free hosting for sites directed at commercial transactions. This publication is an affiliate storefront, so its hosting fit must be assessed before promotion. That is an unresolved policy issue, not a conclusion that a violation occurred (FLG-036). GitHub’s Pages documentation also says it logs visitor IP addresses for security; the disclosure distinguishes that host-side logging from the site’s local browser events (FLG-037).

Review SG-27 (hosting), SG-28 (Search Console), SG-29 (owner confirmation and Special Link testing) and SG-30 (whether and where to deploy the aggregate event collector). None is automatically implemented from this page.

Privacy-preserving measurement and honest reporting

The browser records five event types locally and offers an export. No event is sent to the collector unless a separate endpoint is explicitly configured. The optional collector accepts only the five event types and aggregates daily counts without user IDs, cookies, raw IP addresses or search terms; it is not deployed. The campaign ledger remains empty until an authorized Amazon report provides data. No conversion score, earnings claim or revenue forecast is calculated.
