Product research

What the research layer is designed to do, what it can do today, and the three gates standing between those two states.

Gates

What stops the research layer

Three gates, each traceable to a published rule.
GateRequirementDetailStatusSource
Data source Creators API access. Requires Associates enrollment plus at least 10 qualifying sales in the trailing 30 days. PA-API 5 is deprecated and returns HTTP 403. The replacement API is gated behind a sales threshold this account has not evidenced. Closed S-03
Price data Price and availability may only be shown if Amazon serves the link containing them, or the data arrives via Creators API or PA API under the License. Until API access exists, no price, discount or availability figure can be shown to a reader. Closed S-02
Ratings and reviews Star ratings and customer reviews may only be used if obtained through Creators API or PA API. Observed ratings are therefore held in the internal register only, never rendered on a buyer-facing page. Closed S-02

Capabilities

Designed versus running

The gap between the two columns is the honest state of the automation.

Nothing in the right-hand columns is simulated.
CapabilityDesigned behaviourTodayAutomated
Niche identification Rank candidate categories by the count of verifiable buying questions that can be answered without price data. Done by hand for two categories: air fryers and thermometers. Manual
Trend detection Compare search interest across candidate categories on a rolling basis. Not running. No data source connected. Manual
Price analysis Track observed price over time to spot unusual movement. Not permissible. Blocked by the price-display rule absent API access. Manual
Competition review Survey which questions already have strong published answers. Manual reading, recorded in the content plan. Manual
Commission estimation Estimate earnings per click from category rates. Deliberately not built. Any figure would be a guess dressed as analysis. Manual
Content generation Draft question-shaped guides from verified source material. In use, with every claim traced to a source in the register and every untested statement labelled. AI-assisted
Link management Store intended ASIN and official listing separately from observed redirects. Built. The register keeps the two fields apart and refuses to merge them. Automated
Click and conversion tracking Count the five defined events without identifiers. Client-side only. No collector is deployed, so counts are not yet retained. Partial
Publishing Build the static site, sitemap and feed from one data file. Working. One command rebuilds every page. Automated
Compliance checks Fail the build if a required disclosure is missing from any generated page. Working as a build-time assertion. Automated

On scores and forecasts

No product score, opportunity score or revenue forecast is published. The inputs that would make such a score meaningful do not exist, and a number invented to look analytical is worse than no number.
